# 🌿 Lumina

> A premium editorial-inspired landing page celebrating slow living, nature, and timeless design.


---

## ✨ Overview

Lumina is a modern luxury landing page built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**. Inspired by brands like Apple, Aesop, COS, and Kinfolk, it combines cinematic visuals, smooth interactions, and immersive animations to create a calm, elegant browsing experience.

The website embraces minimalism, storytelling, and premium motion design while maintaining excellent performance and responsiveness.

---
## 🚀 Features

- 🎥 Cinematic full-screen video sections
- 🌼 Interactive orbit animation

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/lumina.git
```

Navigate into the project

```bash
cd lumina
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
